# Keyboard Shortcuts

## Application and project

- `Ctrl+O` — Open project
- `Ctrl+S` — Save the shared project
- `Ctrl+W` — Close the active window
- `Alt+F4` — Close the active window or request project shutdown from the Map Editor
- `Ctrl+Z` / `Ctrl+Y` — Undo / redo in the active command context
- `Alt+Left` / `Alt+Right` — Navigation history where supported
- `Ctrl+Shift+P` — Global command palette

## Local staged editors

- `Ctrl+Enter` — Apply the current Event Editor or Raw Data working session
- `Escape` — Cancel or close the current modal workflow where supported

## Event commands

- `Ctrl+1`, `Ctrl+2`, `Ctrl+3` — Command pages
- `Ctrl+F` — Search
- Arrow keys — Move through commands
- `Enter` or `Space` — Choose
- `Insert` — Insert a command
- `Delete` — Delete selected command
- `Shift+F10` or Menu key — Context menu

## Map canvas

Arrow keys move the keyboard cursor. Shift extends selection where supported. Enter performs the active tool action. The Menu key opens the map context menu.
