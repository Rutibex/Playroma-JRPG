# Publication Packages

The publication exporter turns the active construction into a self-contained deliverable.

## Contents

- exact A1–A5 and B–E PNG sheets;
- plain-text catalogues where enabled;
- Playroma construction JSON and a compact manifest;
- contact sheet;
- standardized showcase scene and control images;
- HTML setup guide;
- HTML tile catalogue;
- README, credits, and licence files.

## Validation gate

When `BlockOnErrors` is enabled, structural or dependency errors prevent normal publication export. Warnings are included in the result but do not block the package.

## Standardized showcase scene

The showcase builder lays out representative sheet content into a deterministic visual scene and emits:

- beauty image;
- visible grid;
- text labels;
- semantic-region colours;
- object-ID colours;
- JSON manifest.

These files are useful for human review and are the structural hand-off to Phase 5.

## Source responsibility

Publication packages include only the current project outputs selected by the user. Playroma Tile does not assert ownership of imported art; creators should provide suitable licence and credits text before distribution.
