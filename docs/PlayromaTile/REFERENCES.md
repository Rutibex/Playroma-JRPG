# Technical References

The implementation is original repository code. The following well-known technique families informed the architecture and terminology:

- Ken Perlin, improved gradient noise.
- Steven Worley, cellular texture bases.
- Andrew Witkin and Michael Kass / Greg Turk, reaction-diffusion texture synthesis.
- Alexei Efros and William Freeman, image quilting.
- Connelly Barnes and collaborators, PatchMatch.
- Michael Cohen and collaborators, Wang-tile texture synthesis.
- standard mathematical morphology, image filtering, palette quantization, and error-diffusion techniques.

No source code or artwork from these publications is copied into the project.
