# Playroma Tile

Playroma Tile is the tile and tileset-authoring subsystem included with Playroma jRPG. It targets RPG Maker MV-compatible 48-pixel tiles, autotiles, tileset metadata, and project integration without redistributing RPG Maker artwork.

## Capabilities

- Sheet editing and PNG import/export.
- RPG Maker MV autotile compilation.
- Procedural material generation and reusable material graphs.
- A1-A5 and B-E tileset construction.
- Ordinary and multi-cell objects, variation families, packing, and placement metadata.
- MV passage, directional blocking, above-character, ladder, bush, counter, damage-floor, and terrain-tag metadata.
- Layered test-map rendering and construction previews.
- Construction completeness/style analysis, duplicate detection, snapshots, and catalogues.
- Publication-package export.
- Safe RPG Maker MV project patching with backups.
