# Original Branding and UX Language

Playroma Sprite Studio uses the independently authored mark in `PlayromaSpriteAssets/branding/playroma-sprite-studio-mark.svg`. It is a geometric pixel-grid “P” followed by a motion trail. It does not reproduce Aseprite branding, icons, color schemes, or interface artwork.

## Product vocabulary

Use Playroma-owned terms in code and UI:

- **Sprite document** for an editable work.
- **Runtime image** for an exported RPG Maker MV PNG.
- **Motion range** for a named animation range when MV context is active.
- **Cell guide** for a format overlay.
- **Asset profile** for versioned engine rules.
- **Install to project** for an atomic runtime export.
- **Studio bridge** for transfer to Music, Sound, Tile, or Animation tools.

Generic pixel-editor terms such as layer, frame, cel, palette, slice, and onion skin describe standard concepts and may be used normally. UI text and icons must be authored for Playroma rather than traced from another application.
