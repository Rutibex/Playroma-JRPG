# Mutable Document Lifecycle

```text
Unloaded -> Loading -> Clean -> Modified -> Saving -> Clean
                         |          |          |
                         |          |          +-> SaveFailed
                         |          +-> ExternallyModified
                         +-> InvalidReadOnly
```

- **Clean** means the edit overlay is empty.
- **Modified** means at least one authorized change exists.
- **InvalidReadOnly** retains original bytes but has no mutable syntax tree.
- **ExternallyModified** means the disk fingerprint no longer matches the
  fingerprint captured at open time.
- **SaveFailed** retains all changes and the transaction recovery information.

Clean documents may be evicted by the workspace cache. Modified documents may
not be evicted. A successful save reparses the generated bytes and establishes
a new clean baseline.
