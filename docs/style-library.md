## Notes

- The numeric filename prefixes provide a stable repository ordering; the style `id` is the semantic identifier used by inheritance and tooling.
- User-authored styles can extend built-in IDs.
- See [Style-Pack Authoring](style-pack-authoring.md) for document structure and contribution guidance.
- Descriptions and the complete musical definitions are stored in the JSON files themselves so the code and documentation do not drift apart.
