# Playroma jRPG Documentation

This directory contains the public documentation for Playroma jRPG. Historical phase delivery reports, build-fix notes, acceptance logs, and temporary validation reports are intentionally excluded from the release tree.

## Start here

- **[Getting Started](GETTING_STARTED.md)** — install prerequisites, build, run, open a project, and make a first safe edit.
- **[User Guide](USER_GUIDE.md)** — main editor workflow, maps, events, database editing, resources, plugins, validation, recovery, and project safety.
- **[Integrated Studios](STUDIOS.md)** — Text, Sprite, Tile, Sound, and Music Studio capabilities and workflows.
- **[Command-Line Interface](CLI.md)** — inspection, validation, references, recovery, assets, round-trip verification, and controlled document edits.
- **[Building and Development](BUILDING.md)** — repository layout, build commands, CI, tests, fixtures, and contributor workflow.
- **[Releasing](RELEASING.md)** — maintainer checklist, tag workflow, and release verification.
