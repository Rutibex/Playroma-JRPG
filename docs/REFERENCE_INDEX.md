# Reference Index

## Model

A `ProjectReference` contains:

- source document and JSON path;
- optional map, record, event, page, and command coordinates;
- target kind and ID/name;
- usage kind;
- confidence (`Exact` or `Heuristic`);
- optional readable context.

## Exact reference sources

The MV extractor covers standard fields including:

- actors to classes and initial equipment;
- classes to learned skills;
- skills/items to animations, elements, states, skills, and common events;
- weapons/armors to type arrays, animations, and traits;
- enemies to skills, drops, traits, and battler assets;
- troops to enemies and troop-page conditions/commands;
- states and other trait-bearing records;
- system starting positions, vehicles, music, sounds, title assets, and party;
- maps to tilesets, encounters, parallax/battleback/audio assets, event page
  conditions, movement routes, and event commands;
- known MV event-command parameters for switches, variables, records, maps,
  assets, movement routes, battles, shops, actors, and enemies.

## Heuristic sources

The scanner recognizes common literal patterns such as:

```javascript
$dataSkills[42]
$gameSwitches.value(17)
$gameVariables.value(9)
$gameActors.actor(3)
```

It also detects readable forms such as `skill: 42` and `map[8]`. Matches in
notes, formulas, scripts, plugin commands, and plugin parameters remain
heuristic even when the numeric text is unambiguous, because plugin semantics
may differ.

## Query operations

- `ProjectReferenceIndex.All`
- `FindInbound(target)`
- `FindOutbound(relativePath)`
- `FindFromRecord(relativePath, recordId)`
- `DependencyReportBuilder.Build(index, target)`

A dependency report separates blocking exact references from review-only
heuristic references.

## Incremental updates

`IncrementalReferenceIndexCoordinator` listens for atomic command events and
invalidates each distinct affected document. `RefreshPendingAsync` reparses only
those documents from their current generated bytes.

For `js/plugins.js`, the indexer reads the current mutable plugin-manifest
document when available, so later plugin-parameter commands will refresh from
current values rather than the original load snapshot.

## CLI

```bash
playroma-jrpg references <project>
playroma-jrpg references <project> --type skill --exact-only
playroma-jrpg dependencies <project> --type map --id 81
```
