# Round-Trip Verification

`roundtrip verify` opens every recognized mutable project document, generates
bytes without changing it, and requires exact byte equality.

```bash
playroma-jrpg roundtrip verify /path/to/project
```

`project copy` copies untouched files byte-for-byte and writes generated bytes
only for supplied modified documents. `project compare` classifies paths as
byte-identical, semantically equivalent JSON, different content, or missing
from either side.

The private stress corpus should be tested only through a locally configured
path. It must never be copied into the public repository or emitted in CI logs.
