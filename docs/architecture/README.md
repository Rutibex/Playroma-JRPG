# Architecture Decisions

Architecture decision records use the following statuses:

- Proposed
- Accepted
- Superseded
- Rejected

A decision that changes compatibility promises, source-of-truth data,
security boundaries, project layout, serialization, rendering, runtime
hosting, or extension isolation requires an ADR.
