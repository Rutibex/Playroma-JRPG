# Procedural Material Samples

Playroma Tile's built-in presets are generated from code when the Material Laboratory opens. No binary artwork is required or distributed.

Suggested first tests:

- Grass — Sharp Pixel Art — Overgrown
- Cobblestone — Classic RPG Maker — Ancient
- Wood Planks — SNES Like — Worn
- Circuit Floor — Clean Science Fiction — Clean
- Water — Soft Painted Fantasy — Clean
- Lava — High Contrast Horror — Cracked
- Reaction Organic — Hand Inked — Corrupted

Save a recipe to place its JSON source and thumbnail under the project's `Materials` directory.
