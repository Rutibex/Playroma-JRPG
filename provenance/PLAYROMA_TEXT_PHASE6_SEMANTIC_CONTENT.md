# Phase 6 semantic-content provenance

The demonstration grammar rules, phrases, semantic labels and miniature corpora added for Playroma Text Studio Phase 6 were authored for this implementation. They were not copied from RPG Maker, commercial games, novels, wiki corpora, or third-party procedural-text datasets.

Phase 6 adds no third-party runtime dependency. It extends Playroma's native C# generation system and the Phase 3 clean-room Tracery-compatible implementation.

User-authored/imported project content retains whatever rights and license obligations apply to that content. Semantic metadata does not alter those rights.
