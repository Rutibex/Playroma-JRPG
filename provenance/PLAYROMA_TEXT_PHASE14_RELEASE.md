# Phase 14 provenance

Phase 14 source, examples, documentation, search algorithms, local provider protocol, release-audit code and tests are original Playroma implementation material.

No model weights, proprietary prompts, commercial corpora, cloud SDK source, API credentials, or third-party AI client binaries are bundled by Phase 14.

Optional provider executables are user-selected external software and remain subject to their own licenses, privacy policies and operating requirements. Playroma only defines an opt-in stdin/stdout process bridge.
