# Playroma Text Studio Phase 4 assets

Phase 4 introduces the WinForms Recipe Designer and live generation playground. Project-authored recipes are stored under `data/PlayromaText/recipes`, while persistent playground favorites/history live under `data/PlayromaText/studio/playground-state.json`.

The UI loads all built-in Phase 1–4 recipes plus project recipes. A project recipe with the same recipe ID replaces the built-in entry in the browser.
