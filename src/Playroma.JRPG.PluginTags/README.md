# Playroma Plugin Tags

`Playroma.JRPG.PluginTags` provides the platform-neutral tag-authoring model used by the editor. It covers tag definitions, typed arguments, note/comment insertion, editing surfaces, validation, and installed-plugin compatibility information.

The Yanfly-specific clean-room catalog and project intelligence live in `Playroma.JRPG.PluginTags.Yanfly`. Third-party plugin JavaScript is not bundled.
