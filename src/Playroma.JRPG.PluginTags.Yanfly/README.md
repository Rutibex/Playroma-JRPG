# Yanfly Compatibility Metadata

This project contains clean-room compatibility metadata and tooling for user-supplied Yanfly Engine Plugins. It does not redistribute YEP JavaScript or long copied help text.

The catalog compiler normalizes supported public metadata into the embedded runtime catalog. Installed-plugin intelligence can inspect an RPG Maker MV project without executing plugin JavaScript and can produce machine-readable compatibility reports.

See the compatibility specifications under `specifications/plugin-tags/yanfly/`.
